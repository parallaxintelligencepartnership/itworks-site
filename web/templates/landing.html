A wall for apps that finished the job.

itworks.dev is a public wall of apps that were built with the itworks plugin for Claude Code and carried all the way through its closeout. Every entry keeps a badge that watches the app after launch, not just on the day it shipped.

Three badge states

  • {{.Badges.Green}} Audited within the last 30 days with zero critical findings open.
  • {{.Badges.Amber}} The audit has gone stale.
  • {{.Badges.Red}} A critical finding is open.

The badge can look bad on purpose.

That is the honest part. The badge reports what is true right now, even when the true answer is amber or red.

The closeout process asks before it publishes anything to this site.

What gets published

  • The display name of the app.
  • One line on what it does.
  • A source label, public or closed, with a repo link only when the source is public.
  • The audit tier and the audit date.
  • How many findings were found, fixed, and accepted.
  • How many critical findings are still open.

Nothing else. No code, no file paths, no secrets, no environment.

No model runs here

This site never runs a model. It only stores and displays closeout summaries. The work happens in visitors' own Claude Code sessions, on their own machines.
